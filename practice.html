Official papers

The papers, years and official sets listed here come from the published list (data/manifest.json). Only the file for the paper and year you choose is downloaded, and it is checked against that list (count, digest, public-safe fields) before it is used. If any file fails, nothing is loaded. This is separate from importing a file from your computer, which is below.

Question bank (local preview)

Published question catalogue

Loads the public catalogue published by this site’s owner (questions only: no answer keys, explanations or scoring). Your browser contacts the catalogue service to fetch it, so the service can see an ordinary web request such as your IP address. Nothing you type or answer is sent. It goes through the same checks as a file import, and it does not start a test.

Or import a file from your computer

Choose a JSON file from your computer. It is read inside this browser only: it is not uploaded or sent anywhere. Use public-safe files only. A file that contains answer keys, explanations or scoring fields is rejected entirely. Only the fields this site understands are loaded. This is a local preview, not an exam engine: nothing is saved remotely, timed by a server or scored.

    Authenticated online examination

    This is different from the local preview above. An online test needs a signed-in account. The server chooses the questions, fixes the marks, marking profile and deadline, saves your answers and keeps the clock. Nothing starts until you press “Start online test”; loading the papers never starts one.
