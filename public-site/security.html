Security

This page describes the intended design. None of it is built or tested yet, and nothing here is a promise that it is.

How GATE Prep Studio is planned to protect your account and keep scoring fair.

  • Scoring and answer keys
  • Accounts and sessions
  • Known limits
  • Report a security problem

Scoring and answer keys

Planned. Tests are meant to be scored on the server, never in your browser. The server picks the questions, sets the deadline and works out the score from the answers it has saved. A score or time sent by your browser is not trusted.

Answer keys are meant to be kept apart from the question data and not sent to your browser while a test is running. Correct answers and explanations are shown only after you submit, and only for that attempt.

The duration of a test follows the fixed rule on the help page. Marking rules are still to be confirmed.

Accounts and sessions

Planned. The server is meant to check who you are on every request and show you only your own data. Passwords are not meant to be stored in readable form, and one-time codes are meant to expire, work once and allow only a few wrong tries. The exact method for protecting passwords is not final.

There is no administrator area on the website. Administration is intended to be done directly in the underlying spreadsheets by a small number of people.

See the Privacy Policy for more.

Known limits

The planned design uses Google Apps Script and Google Sheets, which have limits a purpose-built service would not. In the draft design these are expected to apply:

Capacity. Only a limited number of people can use the site at the same moment.

Abuse controls. Repeated attempts cannot be blocked by network address, so abuse controls are weaker than on a dedicated service.

Logs. Activity logs could be changed by anyone with edit access to the spreadsheets.

Availability. Downtime or data loss is possible. See the Terms of Use.

These are expected limits from the draft design, not measured results.

Report a security problem

If you find a weakness, please report it instead of using it. Do not access other people’s data, and do not try to read answer keys outside a normal test.
